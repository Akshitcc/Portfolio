# Akshit Kumar | Portfolio

Personal portfolio site for **Akshit Kumar**, Senior QA Engineer (AI & LLM Testing | FinTech & Healthcare).

Live at **https://akshitcc.github.io/Portfolio/**

## Stack
Plain HTML, CSS and a little vanilla JavaScript. No build step, no trackers.

## Files
- `index.html`: page content and SEO / Open Graph meta
- `styles.css`: styles (dark theme by default, light theme via `prefers-color-scheme`)
- `script.js`: mobile nav, scroll reveal, active-section highlighting
- `Akshit_Kumar_Resume.pdf`: downloadable resume
- `.nojekyll`: serve files as-is on GitHub Pages

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy
Push to the `main` branch of the `Akshitcc/Portfolio` repository. GitHub Pages serves it from the repo root at **https://akshitcc.github.io/Portfolio/**.
